Kaise bana?

Ye demo kaise bana — 4 steps

Koi rocket science nahi. Yehi 4 steps har React Bits wali website ke hote hain.

01

Component chuno

reactbits.dev kholo — 215+ animations mein se pasand wala chuno aur live preview dekho. Text, background, card, button — sab categories hain.

02

Source copy karo

CLI (npx jsrepo add ...) ya copy-paste se component ka source apne Next.js project mein daalo. Code tumhara ho jata hai — koi heavy library install nahi.

03

Props se tune karo

Colors, speed, size — sab props se badalte hain. Jaise is page ka Aurora violet-cyan-pink hai, aur BlurText words se reveal hota hai.

04

Build + deploy karo

npm run build karke static export nikalo, phir GitHub Pages ya Vercel par live kar do. Bas — animation wali website ready.
